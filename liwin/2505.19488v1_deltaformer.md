# Understanding Transformer from the Perspective of Associative Memory
(June 5, 2025)

###### Abstract

In this paper, we share our reflections and insights on understanding Transformer architectures through the lens of associative memory—a classic psychological concept inspired by human cognition. We start with the basics of associative memory (think simple linear attention) and then dive into two dimensions:

Memory Capacity: How much can a Transformer really remember, and how well? We introduce retrieval SNR to measure this and use a kernel perspective to mathematically reveal why Softmax Attention is so effective. We also show how FFNs can be seen as a type of associative memory, leading to insights on their design and potential improvements.

Memory Update: How do these memories learn and evolve? We present a unified framework for understanding how different Transformer variants (like DeltaNet and Softmax Attention) update their "knowledge base". This leads us to tackle two provocative questions: 1. Are Transformers fundamentally limited in what they can express, and can we break these barriers?  2\. If a Transformer had infinite context, would it become infinitely intelligent?

We want to demystify Transformer architecture, offering a clearer understanding of existing designs. This exploration aims to provide fresh insights and spark new avenues for Transformer innovation.

##  1 Introduction

Transformer models [42] have emerged as foundational architectures in modern artificial intelligence (AI), demonstrating remarkable versatility and groundbreaking performance across diverse domains, including natural language processing [4], computational biology [16], computer vision [7], and multimodal tasks [29, 30]. Despite their evident success, the internal mechanisms underlying Transformers remain complex and not fully understood, posing significant challenges for theoretical interpretation and principled improvements.

In our journey towards demystifying Transformer architectures, we have discovered that the concept of associative memory, drawn from human cognition, provides a uniquely intuitive and insightful perspective. Associative memory, in psychological terms, describes the brain’s ability to form and recall connections between seemingly unrelated entities [41].

Interestingly, we find that Transformer architectures—including their core components, the Self-Attention mechanism and Feed-Forward Networks (FFNs)—can be elegantly understood as implementations of associative memory. More specifically, the Attention mechanism dynamically forms short-term, contextual associations, while FFNs encode persistent, long-term associative memories distilled during training. This unified viewpoint enables a deeper, more structured understanding of Transformer behavior and offers practical insights for architectural innovation.

Our analysis begins with the classical cumulative outer-product model of associative memory, essentially the simplest representation of linear attention mechanisms. From this starting point, we systematically examine the Transformer architecture along two fundamental dimensions: memory capacity and memory update. For each dimension, we clarify how existing designs fit into a generalized associative memory framework and highlight theoretical and empirical differences. Through this lens, we also uncover opportunities for novel model designs and improvements.

Memory Capacity. To understand and quantify memory capacity, we introduce the retrieval Signal-to-Noise Ratio (SNR) as a precise theoretical measure of associative memory retrieval quality. From a kernel perspective, we mathematically demonstrate why Softmax Attention (with exponential kernel) significantly outperforms Linear Attention in retrieval accuracy and memory capacity. Furthermore, we unify the Transformer FFN as an associative memory employing a ReLU-like kernel and analyze its properties. From this unified perspective, we raise a question:

  * •

Is it possible to achieve a unified understanding of the diverse designs for Attention and FFNs?

By comparing Attention (exponential kernel) and FFN, we provide a principled explanation for their architectural differences, discuss empirical phenomena such as polysemanticity, and propose potential avenues for enhancing both components through kernel design, multihead mechanisms, sparsity, and gating functions.

Memory Update. We then explore the mechanisms by which associative memories can be updated. Starting again from the classical linear model, we propose a general recurrent form of memory update and its corresponding optimization objective. Under this generalized framework, we reinterpret various Transformer designs—including Linear Attention [17], DeltaNet [33, 48], Gated Attention [47], and Softmax Attention—as specific instances with distinct memory update strategies. By examining various memory update strategies, we raise the following questions:

  * •

Does Transformers suffer from an intrinsic limitation in expressive power, and can it be improved?

  * •

If a Transformer’s context length grows infinitely, will the model itself become infinitely intelligent?

Regarding the first question, we discuss model expressivity because, when measured by circuit complexity, different memory update strategies can significantly affect a model’s expressivity. For instance, DeltaNet, which employs a delta-rule update strategy, demonstrates superior expressivity compared to Transformers using Softmax Attention [13, 38, 24]. Based on this insight, we introduce a novel associative memory model that combines the high retrieval accuracy of Softmax Attention with the delta-rule update mechanism of DeltaNet, thereby achieving improved memory management and stability. Through theoretical proof, we demonstrate that the proposed model’s expressivity exceeds that of standard Transformers, revealing considerable potential.

For the second question, a common intuition suggests that “Transformers supporting longer contexts can unlock greater intelligence.” For example, reasoning language models can solve increasingly complex problems when given more time to think. This raises the question: is it theoretically feasible to build a Transformer supporting unlimited context to achieve greater potential intelligence? In-context learning actually corresponds to continuous updates of associative memory. From associative memory update perspective, we discover that theoretically, as context increases, memory may gradually converge, leading to degradation in in-context learning. This indicates potential theoretical challenges in constructing Transformers supporting infinite context. Additionally, we provide an in-depth analysis of several mitigating factors that could prevent memory convergence.

While several existing studies have explored associative-memory interpretations of Transformer architectures [31, 45, 3], we hope our exploration offers fresh insights, a clearer theoretical understanding, and inspiration for future Transformer innovations. In the conclusion section, our exploration culminates in a forward-looking discussion, where we pose several fundamental questions about the future trajectory of AI architectures, inspired by these associative memory principles.111Consider this post less as a formal research paper and more as a blog-style sharing of our current reflections, intended to spark discussion as one might in a collaborative team meeting.

##  2 Associative Memory

_What is associative memory?_ According to Wikipedia 222https://en.wikipedia.org/wiki/Associative_memory_(psychology), associative memory refers to the ability to learn and remember relationships between different entities, even if these entities themselves are not directly related. For instance, a person who has visited Paris and seen the Eiffel Tower is likely to form an association between Paris and Eiffel Tower in the brain. Consequently, when Paris is mentioned in the future, he will likely recall the Eiffel Tower. Describing this process academically, Paris serves as a _key_ that triggers the recall of a corresponding _value_ stored in associative memory, in this case, the Eiffel Tower. This capability underpins human cognitive functions, enabling us to efficiently retrieve related information (values) from a single idea or perception (key).

_How to formalize the associative memory?_ Let us define a matrix 𝑺\bm{S} to represent associative memory. 𝑺\bm{S} is updated continuously and varies with time. For instance, by adding a subscript tt to get 𝑺t\bm{S}_{t}, we represent the associative memory at time tt. We can define the “information” to be stored at each moment as a key-value vector pair (𝒌,𝒗)(\bm{k},\bm{v}), where 𝒌∈ℝdk,𝒗∈ℝdv,𝑺∈ℝdv×dk\bm{k}\in\mathbb{R}^{d_{k}},\bm{v}\in\mathbb{R}^{d_{v}},\bm{S}\in\mathbb{R}^{d_{v}\times d_{k}}.

How are key-value pairs specifically memorized by 𝑺\bm{S}? A classical modeling approach is to directly accumulate the outer product matrices of key-value pairs:

| 𝑺t=∑i=1t𝒗i​𝒌i⊤.\displaystyle\bm{S}_{t}=\sum_{i=1}^{t}\bm{v}_{i}\bm{k}_{i}^{\top}. |  | (1)  
---|---|---|---  
  
Then how to retrieve the stored value 𝒗\bm{v} from memory 𝑺\bm{S} based on key 𝒌\bm{k}? We can define a function f𝑺:ℝdk→ℝdvf_{\bm{S}}:\mathbb{R}^{d_{k}}\to\mathbb{R}^{d_{v}} parameterized by 𝑺\bm{S}, such that f𝑺​(𝒌i)f_{\bm{S}}(\bm{k}_{i}) approximates 𝒗i\bm{v}_{i} as closely as possible for any stored (𝒌i,𝒗i)(\bm{k}_{i},\bm{v}_{i}). f𝑺f_{\bm{S}}, also called the associative map, essentially simulates the recall process of memory. The recall process is typically failure tolerant [15, 19]. Even if 𝒌i\bm{k}_{i} is perturbed somewhat, defined as query 𝒒i≈𝒌i\bm{q}_{i}\approx\bm{k}_{i}, f𝑺​(𝒒i)f_{\bm{S}}(\bm{q}_{i}) can still recall a similar 𝒗i\bm{v}_{i}. A classical f𝑺f_{\bm{S}} is a simple linear transformation, specifically f𝑺​(𝒒)=𝑺​𝒒f_{\bm{S}}(\bm{q})=\bm{S}\bm{q}.

In summary, we find that an associative memory model is determined by two components: the update mechanism of 𝑺\bm{S} and the associative map f𝑺f_{\bm{S}}.

_Transformer can actually be interpreted as associative memory._ Taking the attention layer, a core component of Transformer, as an example, its output 𝒐t\bm{o}_{t} at time tt can be calculated as:

---|---|---|---  
  
Define the feature mapping corresponding to the exp kernel function as ϕ​(⋅)\phi(\cdot), such that exp⁡(𝒌⊤​𝒒/dk)=ϕ​(𝒌)⊤​ϕ​(𝒒)\exp(\bm{k}^{\top}\bm{q}/\sqrt{d_{k}})=\phi(\bm{k})^{\top}\phi(\bm{q}). For simplicity, we ignore the normalization term. The calculation of 𝒐t\bm{o}_{t} can be re-written as:

| 𝒐t\displaystyle\bm{o}_{t} | =∑i=1tϕ​(𝒌i)⊤​ϕ​(𝒒t)​𝒗i\displaystyle=\sum_{i=1}^{t}\phi(\bm{k}_{i})^{\top}\phi(\bm{q}_{t})\bm{v}_{i} |   
---|---|---|---  
|  | =∑i=1t𝒗i​ϕ​(𝒌i)⊤⏟𝑺t​ϕ​(𝒒t).\displaystyle=\underbrace{\sum_{i=1}^{t}\bm{v}_{i}\phi(\bm{k}_{i})^{\top}}_{\bm{S}_{t}}\phi(\bm{q}_{t}). |  | (3)  
  
Thus, we discover that the attention layer is a form of associative memory, where 𝑺t=∑i=1t𝒗i​ϕ​(𝒌i)⊤\bm{S}_{t}=\sum_{i=1}^{t}\bm{v}_{i}\phi(\bm{k}_{i})^{\top} and the associative map f𝑺​(𝒒)=𝑺​ϕ​(𝒒)f_{\bm{S}}(\bm{q})=\bm{S}\phi(\bm{q}).

In fact, another core component of Transformer, the feed-forward network (FFN), can also be viewed as a form of associative memory (see the discussion on the ReLU kernel in Sec. 2.1.1).

Although both the attention layer and the feed-forward network (FFN) maintain memory that can be categorized as associative memory, they differ in terms of the lifespan of the stored information. Specifically, the attention layer maintains a short-term contextual memory organized in an associative manner. During inference, this memory, known as the key-value (KV) cache, is discarded once inference is completed. In contrast, the FFN maintains a persistent, long-term associative memory. This memory is compressed via gradient descent during training and encodes knowledge relevant to the training dataset. Typically, it remains unchanged after training concludes.

Since Transformer belongs to a type of associative memory, we can understand Transformer and its various variants from the perspective of associative memory. As a memory, it is natural to examine its properties from two dimensions: memory capacity (Sec. 2.1) and memory update (Sec. 2.2). To keep the discussion general, i.e., covering as many model designs as possible, for each dimension we will start from the basic model corresponding to Eq. 1, gradually extending it and analyzing different influencing factors.

###  2.1 Memory Capacity

Specifically, considering 𝒒t=𝒌i\bm{q}_{t}=\bm{k}_{i}, retrieving any 𝒗i\bm{v}_{i} is performed as:

| 𝒐t=𝑺t​𝒌i=𝒗i​(𝒌i⊤​𝒌i)⏟signal term+∑j≠i𝒗j​(𝒌j⊤​𝒌i)⏟noise term.\displaystyle\bm{o}_{t}=\bm{S}_{t}\bm{k}_{i}=\underbrace{\bm{v}_{i}(\bm{k}_{i}^{\top}\bm{k}_{i})}_{\text{signal term}}+\underbrace{\sum_{j\neq i}\bm{v}_{j}(\bm{k}_{j}^{\top}\bm{k}_{i})}_{\text{noise term}}. |  | (4)  
---|---|---|---  
  
To achieve accurate retrieval, it is required that vectors {𝒌1,…,𝒌t}\\{\bm{k}_{1},\dots,\bm{k}_{t}\\} be orthonormal, implying that in Eq. 4, 𝒌i⊤​𝒌i=1\bm{k}_{i}^{\top}\bm{k}_{i}=1 and 𝒌j⊤​𝒌i=0\bm{k}_{j}^{\top}\bm{k}_{i}=0 for j≠ij\neq i.

What is the capacity of the associative memory 𝑺t\bm{S}_{t}? That is, under the condition of accurate recall, what is the maximum number of key-value pairs it can store? Intuitively, the linear space spanned by vectors 𝒌i\bm{k}_{i} has only dkd_{k} orthogonal bases. If the number of stored key-value pairs n≫dkn\gg d_{k}, the “noise” term ∑j≠i𝒗j​(𝒌j⊤​𝒌i)\sum_{j\neq i}\bm{v}_{j}(\bm{k}_{j}^{\top}\bm{k}_{i}) in Eq. 4 becomes non-zero, resulting in increased retrieval error.

To quantitatively analyze the performance of fuzzy associative memory retrieval, we define a metric similar to Signal-to-Noise Ratio (SNR). Specifically, consider the general retrieval operation:

| 𝑺t​𝒌i=c​𝒗i+𝒓,\displaystyle\bm{S}_{t}\bm{k}_{i}=c\bm{v}_{i}+\bm{r}, |  | (5)  
---|---|---|---  
  
where the first term represents the signal, scaled by factor cc, and the second term represents the noise 𝒓\bm{r}. The inverse SNR is thus defined as:

| SNR−1=𝔼𝒗j,𝒌j​[‖𝒓‖2c2​‖𝒗i‖2].\displaystyle\mathrm{SNR}^{-1}=\mathbb{E}_{\bm{v}_{j},\bm{k}_{j}}\left[\frac{\|\bm{r}\|^{2}}{c^{2}\|\bm{v}_{i}\|^{2}}\right]. |  | (6)  
---|---|---|---  
  
This indicator intuitively measures the proportion of noise relative to the signal. A larger value indicates a higher noise component, resulting in lower retrieval accuracy. We consider a scenario where key vectors 𝒌j∈ℝdk\bm{k}_{j}\in\mathbb{R}^{d_{k}} and value vectors 𝒗j∈ℝdv\bm{v}_{j}\in\mathbb{R}^{d_{v}} are independently and identically distributed (i.i.d.) standard Gaussian vectors. Under this assumption, we can quantitatively calculate the inverse SNR, providing an explicit measure of retrieval accuracy degradation.

For the linear form in Eq. 4, the signal term is c=𝒌i⊤​𝒌ic=\bm{k}_{i}^{\top}\bm{k}_{i}, and the noise is given by 𝒓=∑j≠i𝒗j​(𝒌j⊤​𝒌i)\bm{r}=\sum_{j\neq i}\bm{v}_{j}(\bm{k}_{j}^{\top}\bm{k}_{i}). As shown in the appendix 6, this leads to the following approximate expression:

| SNRLinear−1≈Ndk.\displaystyle\boxed{\mathrm{SNR}^{-1}_{\text{Linear}}\approx\frac{N}{d_{k}}}. |  | (7)  
---|---|---|---  
  
This result intuitively indicates that the noise increases linearly with the number of stored key-value pairs NN333We use NN instead of the earlier variable tt to emphasize the total number of stored key-value pairs. and decreases inversely with the dimensionality of the key vectors dkd_{k}. Practically, this implies that for reliable associative recall in linear form, the number of stored pairs should be on the order of or less than the dimensionality of the key vectors: dk≳Nd_{k}\gtrsim N.

Beyond this threshold, retrieval accuracy deteriorates rapidly due to the accumulation of noise, severely restricting the effective capacity of the associative memory. This also explains why linear Transformers often underperform in precise long-context retrieval tasks [20, 28].

We next introduce two strategies to improve associative memory capacity: kernel mapping and sparsity. These techniques are widely used in attention mechanisms and feedforward layers, respectively. While traditionally treated as separate design choices, we show that they are not mutually exclusive and, in fact, share substantial structural similarities.

####  2.1.1 Kernel Mapping

Since the memory capacity is limited by dkd_{k}, we can apply a kernel function to map vectors to a higher-dimensional space, allowing query-key matching to occur in this expanded space. Intuitively, in higher-dimensional spaces, vectors become more distinguishable from each other, making them easier to separate, reducing retrieval errors, and enabling memory to store more values 𝒗\bm{v}. This insight is closely related to the Johnson–Lindenstrauss lemma and superposition theory [14, 9].

By introducing a kernel function κ​(𝒙,𝒚)=ϕ​(𝒙)⊤​ϕ​(𝒚)\kappa(\bm{x},\bm{y})=\phi(\bm{x})^{\top}\phi(\bm{y}), the mapping process becomes f𝑺t​(𝒌t)=𝑺t​ϕ​(𝒌t)f_{\bm{S}_{t}}(\bm{k}_{t})=\bm{S}_{t}\phi(\bm{k}_{t}). Correspondingly, the associative memory and the recall operation are:

| 𝑺t=∑i=1t𝒗i​ϕ​(𝒌i)⊤,\displaystyle\bm{S}_{t}=\sum_{i=1}^{t}\bm{v}_{i}\phi(\bm{k}_{i})^{\top}, |  | (8)  
---|---|---|---  
| 𝒐t=𝑺t​ϕ​(𝒒t)=∑i=1t𝒗i​(ϕ​(𝒌i)⊤​ϕ​(𝒒t))=∑i=1t𝒗i​κ​(𝒌i,𝒒t).\displaystyle\bm{o}_{t}=\bm{S}_{t}\phi(\bm{q}_{t})=\sum_{i=1}^{t}\bm{v}_{i}\left(\phi(\bm{k}_{i})^{\top}\phi(\bm{q}_{t})\right)=\sum_{i=1}^{t}\bm{v}_{i}\kappa(\bm{k}_{i},\bm{q}_{t}). |  | (9)

Next, we analyze two kernel functions particularly significant in associative memory: the exponential (Exp) kernel and the ReLU kernel, due to their close connections to the attention mechanism and feed-forward network (FFN) commonly employed in modern transformer architectures.

#####  Kernel.

As mentioned above, the distinct kernels employed by the two modules raise an intriguing question: why do feed-forward networks (FFNs) adopt the ReLU kernel instead of a more precise one like Exp kernel?

We propose the following hypothesis: _A kernel with lower retrieval precision encourages a more polysemantic key–value memory: multiple unrelated facts can be stored under the same key space._ This is commonly referred to as superposition [14, 9] in interpretability research. This enlarges the amount of abstract, compressed knowledge that fits into a fixed-width associative memory. Conversely, Attention layers frequently need to pinpoint a specific token from the current context (e.g. induction heads [25]), and therefore benefit from a highly precise, more monosemantic kernel. FFNs, in contrast, must distill the entire training corpus into static weights; the ability to superpose many fragments of information under one vector is therefore advantageous, even at the cost of noisier recall.

A piece of empirical evidence comes from Anthropic’s replacement of ReLU with the Softmax Linear Unit (SoLU) activation [8]:

| κSoLU​(𝒙,𝒚)=(𝒙⊤​𝒚)​exp⁡(𝒙⊤​𝒚τ),\displaystyle\kappa_{\text{SoLU}}(\bm{x},\bm{y})=(\bm{x}^{\top}\bm{y})\exp\left(\frac{\bm{x}^{\top}\bm{y}}{\tau}\right), |  | (16)  
---|---|---|---  
  
which can be viewed as a multiplicative blend of the linear and exponential kernels. They observed that hidden representations became markedly _monosemantic_ , yet model accuracy on knowledge-heavy benchmark TriviaQA deteriorated.

In Appendix 6, we derive the inverse SNR for the SoLU kernel:

| SNRSoLU−1≈5​Ndk​exp⁡(2​dk).\displaystyle\boxed{\mathrm{SNR}^{-1}_{\text{SoLU}}\approx\frac{5N}{d_{k}\exp(2\sqrt{d_{k}})}.} |  | (17)  
---|---|---|---  
  
This indicates that SoLU offers a higher retrieval precision than ReLU, consistent with its observed monosemantic behavior. Together, these findings support our broader hypothesis: the choice of kernel fundamentally mediates a tradeoff between knowledge density (amount of information stored) and retrieval precision (specificity of memory access) in neural architectures. We leave a fuller exploration of kernel choice for knowledge retention versus contextual recall to future work.

#####  Normalization.

Compared with the associative-recall formulation introduced earlier (Eq. 9), the standard Softmax Attention includes an additional normalization factor:

| 𝑺t​ϕ​(𝒒t)=∑i=1t𝒗i​exp⁡(𝒒t⊤​𝒌i)∑i=1texp⁡(𝒒t⊤​𝒌i),\displaystyle\bm{S}_{t}\phi(\bm{q}_{t})\;=\;\frac{\sum_{i=1}^{t}\bm{v}_{i}\,\exp\bigl{(}\bm{q}_{t}^{\top}\bm{k}_{i}\bigr{)}}{\sum_{i=1}^{t}\exp\bigl{(}\bm{q}_{t}^{\top}\bm{k}_{i}\bigr{)}}, |  | (18)  
---|---|---|---  
  
that the FFN omits. The most closely related work to ours on incorporating normalization into FFNs is NormFormer [37], which introduces a LayerNorm operation immediately after the nonlinear activation (kernel function), resulting in improved training stability. Because many linear-attention variants[20, 40, 48] have shown that this factor can be replaced by a simple per-head norm, we regard normalization primarily as a mechanism for training stability rather than a fundamental design requirement.

#####  Multihead.

Multihead attention slice 𝒒,𝒌,𝒗\bm{q},\bm{k},\bm{v} into nhn_{h} heads and use output matrix 𝑾O∈ℝd×dh​nh\bm{W}_{O}\in\mathbb{R}^{d\times d_{h}n_{h}} to combine per-head result:

| [𝒒j,1;𝒒j,2;…;𝒒j,nh]=𝒒t,\displaystyle[\bm{q}_{j,1};\bm{q}_{j,2};\dots;\bm{q}_{j,n_{h}}]=\bm{q}_{t}, |  | (19)  
---|---|---|---  
| [𝒌i,1;𝒌i,2;…;𝒌i,nh]=𝒌i,\displaystyle[\bm{k}_{i,1};\bm{k}_{i,2};\dots;\bm{k}_{i,n_{h}}]=\bm{k}_{i}, |  | (20)  
| [𝒗i,1;𝒗i,2;…;𝒗i,nh]=𝒗i,\displaystyle[\bm{v}_{i,1};\bm{v}_{i,2};\dots;\bm{v}_{i,n_{h}}]=\bm{v}_{i}, |  | (21)  
| 𝒐t,⋅=∑i=1t𝒗i,⋅​κ​(𝒒t,⋅,𝒌i,⋅),\displaystyle\bm{o}_{t,\cdot}=\sum_{i=1}^{t}\bm{v}_{i,\cdot}\,\kappa(\bm{q}_{t,\cdot},\bm{k}_{i,\cdot}), |  | (22)  
| 𝒐t=𝑾O​[𝒐t,1;𝒐t,2;…;𝒐t,nh].\displaystyle\bm{o}_{t}=\bm{W}_{O}[\bm{o}_{t,1};\bm{o}_{t,2};\dots;\bm{o}_{t,n_{h}}]. |  | (23)  
  
This slicing mechanism allows multihead attention to compute nhn_{h} distinct similarity patterns for the same query-key pair. As in our earlier analysis of the exponential kernel, the multihead mechanism can trade off retrieval precision for expressivity when using stronger kernels, or alternatively, enhance superposition to improve knowledge capacity. Moreover, from an intuitive perspective, the output projection matrix 𝑾O\bm{W}_{O} in multi-head attention can reduce the noise term in the Eq. 4 777For instance, in Multi-Query Attention (MQA), if 𝑾O\bm{W}_{O} learns to compute a simple average over nhn_{h} heads with shared keys and values, the variance of the noise term is reduced by a factor of nhn_{h} compared to a single-head attention with the same key/value dimensionality.. In the original Transformer paper, the authors experimented with replacing the entire FFN layer with multihead attention[42], observing some performance improvements. Given that attentions have been significantly optimized in modern GPUs[6, 5, 34], we argue that introducing multihead mechanisms into FFNs, i.e. slicing 𝒙,𝑾Ki,𝑾Vi\bm{x},{\bm{W}_{K}}_{i},{\bm{W}_{V}}_{i} in Eq. 14, deserves renewed consideration, and we leave exploration of this idea to future work.

#####  Sparsity.

It is easy to see that when numbers of keys and values becomes large, the keys relevant to each query will inevitably be sparse. The simplest approach to incorporating sparsity in FFN is through the Mixture-of-Experts (MoE) mechanism [36, 11]. Consider an FFN with EE expert subnetworks, each parameterized by separate weight matrices 𝑾K(e),𝑾V(e)∈ℝ(m/E)×d\bm{W}_{K}^{(e)},\bm{W}_{V}^{(e)}\in\mathbb{R}^{(m/E)\times d}. Therefore, the gating function geg_{e} in Attention needs to depend on the set of key vectors {𝒌i}i∈Expert​(e)\\{\bm{k}_{i}\\}_{i\in\text{Expert}(e)}. ##### Gating.

Another prevalent architectural choice in FFNs is gating, as exemplified by the SwiGLU activation [35]. SwiGLU gating introduces multiplicative interactions between two linear transformations of the input, defined as:

| FFNSwiGLU​(𝒙)\displaystyle\text{FFN}_{\text{SwiGLU}}(\bm{x}) | =𝑾V⊤((𝑾G𝒙)⊙Swish(𝑾U𝒙)),\displaystyle=\bm{W}_{V}^{\top}\bigr{(}\left(\bm{W}_{G}\bm{x}\right)\odot\text{Swish}\left(\bm{W}_{U}\bm{x}\right)\bigl{)}, |  | (28)

where 𝑾K,𝑾G,𝑾V∈ℝm×d\bm{W}_{K},\bm{W}_{G},\bm{W}_{V}\in\mathbb{R}^{m\times d} are parameter matrices, ⊙\odot denotes element-wise multiplication, and Swish is given by Swish​(z)=z⋅Sigmoid​(z)\text{Swish}(z)=z\cdot\text{Sigmoid}(z) .

Expressed in the associative-memory framework, SwiGLU can be rewritten as:

| FFNSwiGLU​(𝒙)\displaystyle\text{FFN}_{\text{SwiGLU}}(\bm{x}) | =∑i=1m𝑾Vi⏟𝒗i​(𝑾Gi⊤​𝒙)⏟gi​(𝒙)​Swish⏟κ​(⋅,⋅)​(𝑾Ki⊤⏟𝒌i​𝒙⏟𝒒t),\displaystyle=\sum_{i=1}^{m}\underbrace{{\bm{W}_{V}}_{i}}_{\bm{v}_{i}}\underbrace{({\bm{W}_{G}}_{i}^{\top}\bm{x})}_{g_{i}(\bm{x})}\underbrace{\text{Swish}\vphantom{{\bm{W}_{K}}_{i}}}_{\kappa(\cdot,\cdot)}\bigl{(}\underbrace{{\bm{W}_{K}}_{i}^{\top}}_{\bm{k}_{i}}\underbrace{\bm{x}\vphantom{{\bm{W}_{K}}_{i}}}_{\bm{q}_{t}}\bigr{)}, |  | (29)

where (𝑾Gi⊤​𝒙)({\bm{W}_{G}}_{i}^{\top}\bm{x}) is the additionally introduced gating term gi​(𝒙)g_{i}(\bm{x}), which can amplify or suppress the response of query to the specific key. Intuitively, this gating mechanism provides a dynamic, input-dependent modulation. Recent linear transformers have experimented with gating mechanisms within attention layers, such as Gated Linear Attention [47]. The gating term is defined as (normalization terms omitted):

| 𝒐t,gated\displaystyle\bm{o}_{t,\text{gated}} | =∑i=1t𝒗i​gi​(𝒙i:t)​κ​(𝒒t,𝒌i),\displaystyle=\sum_{i=1}^{t}\bm{v}_{i}\,{g_{i}}(\bm{x}_{i:t})\,\kappa(\bm{q}_{t},\bm{k}_{i}), |  | (30)  
---|---|---|---|---

where αj\alpha_{j} parameterized via a linear layer followed by sigmoid on hidden stats 𝒙j\bm{x}_{j}. A more recent work, FoX [21], also incorporates gating into Softmax attention, adopting a formulation essentially identical to the one we present here.

Interestingly, gating mechanisms in attention are usually interpreted as a form of forgetting mechanism and thus typically represented as a cumulative product of gate values between 0 and 1 (implemented via sigmoid functions). However, observing the gating in FFNs, we notice the absence of such cumulative mechanisms. We conjecture that defining the gating function simply as gi​(𝒙i:t)=𝑾G​(𝒙i)⊤​𝒙tg_{i}(\bm{x}_{i:t})={\bm{W}_{G}(\bm{x}_{i})}^{\top}\bm{x}_{t} may achieve a similar effect while being simpler to implement. We leave the investigation of this hypothesis for future work. As for why gating mechanisms are effective in general, we encourage further research and exploration into their underlying principles and theoretical explanations.

###  2.2 Memory Update

_How is associative memory updated?_ For example, by reformulating Eq. 1, we obtain:

| 𝑺t\displaystyle\bm{S}_{t} | =(∑i=1t−1𝒗i​𝒌i⊤)⏟𝑺t−1+𝒗t​𝒌t⊤\displaystyle=\underbrace{\left(\sum_{i=1}^{t-1}\bm{v}_{i}\bm{k}_{i}^{\top}\right)}_{\bm{S}_{t-1}}+\bm{v}_{t}\bm{k}_{t}^{\top} |   
---|---|---|---  
|  | =𝑺t−1+𝒗t​𝒌t⊤.\displaystyle=\bm{S}_{t-1}+\bm{v}_{t}\bm{k}_{t}^{\top}. |  | (32)  
  
This indicates that, for classical associative memory, the update at time step tt is directly realized by adding the outer product of the latest vectors 𝒗t\bm{v}_{t} and 𝒌t\bm{k}_{t}. We typically refer to Eq. 32 as the recurrent form of the classical associative memory. If we interpret this equation as a single-step gradient descent update on 𝑺\bm{S} (ignoring the learning rate), we have:

| 𝑺t=𝑺t−1−(−𝒗t​𝒌t⊤)⏟∂ℒt∂𝑺t−1,\displaystyle\bm{S}_{t}=\bm{S}_{t-1}-\underbrace{(-\bm{v}_{t}\bm{k}_{t}^{\top})}_{\frac{\partial\mathcal{L}_{t}}{\partial\bm{S}_{t-1}}}, |  | (33)  
---|---|---|---  
  
where ℒt\mathcal{L}_{t} represents the optimization objective corresponding to the memory update, which can be derived explicitly:

| ℒt​(𝑺t−1)=−⟨𝑺t−1​𝒌t,𝒗t⟩,\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=-\langle\bm{S}_{t-1}\bm{k}_{t},\bm{v}_{t}\rangle, |  | (34)  
---|---|---|---  
  
with ⟨⋅,⋅⟩\langle\cdot,\cdot\rangle denoting the inner product. Intuitively, this objective aims to update 𝑺\bm{S} such that recalling 𝒗t\bm{v}_{t} from the updated memory using 𝒌t\bm{k}_{t} is as effective as possible. However, a clear drawback of this objective is that, besides promoting a large inner product between 𝑺​𝒌t\bm{S}\bm{k}_{t} and 𝒗t\bm{v}_{t}, it also encourages the norm of 𝑺​𝒌t\bm{S}\bm{k}_{t} to grow without bound, potentially causing numerical instability. In practice, this issue can be mitigated by, for instance, introducing decay mechanisms on 𝑺\bm{S} [47]. Various improved approaches to memory updating will be discussed in detail below.

To facilitate discussions on different memory update methods, we first define a general recurrent form of associative memory as follows:

| 𝑺t=𝑨t​𝑺t−1​𝑩t+𝑪t,\displaystyle\bm{S}_{t}=\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t}+\bm{C}_{t}, |  | (35)

####  2.2.1 Vignette 2: Softmax Attention with Delta Rule

What insights can we gain from the comparison of different associative memory models summarized in Table 2? Two core points underpin these distinct models:

  * •

_How to improve the accuracy of memory recall?_ One effective approach is the kernel trick. For instance, softmax attention employs an exponential kernel function. As discussed in Sec. 2.1.1, this method efficiently enhances memory recall accuracy by performing additional kernel computations without increasing spatial complexity.

  * •

_How to effectively manage memory update to avoid such as the explosive growth of the spectral norm of 𝐒\bm{S}?_ It can be mathematically proved that memory models of the form 𝑺t=𝑺t−1+𝒗i​𝒌i⊤\bm{S}_{t}=\bm{S}_{t-1}+\bm{v}_{i}\bm{k}_{i}^{\top} inevitably experience growth in the spectral norm of 𝑺\bm{S} over time, resulting in numerical instability, regardless of whether the kernel trick is utilized.

Softmax attention addresses this issue by incorporating a normalization term, which is approximately equivalent to scaling the newly written information 𝒗t\bm{v}_{t} by a decaying factor 1t\frac{1}{t}. This implies that information closer to the future is increasingly attenuated, i.e., the write-in term 1t​𝒗t​𝒌t⊤→0\frac{1}{t}\bm{v}_{t}\bm{k}_{t}^{\top}\to 0, thereby slowing down the growth of the spectral norm of 𝑺\bm{S}. The assumption that information closer to the future is less important is unreasonable.

Generally, it is more reasonable to assume that older information is less important. Therefore, reversing the decay direction makes more sense. Gated linear attention implements this reversed decay by introducing an exponential decay factor diag​(𝝀)\text{diag}(\bm{\lambda}) in its recurrent form.

Nevertheless, older information is not necessarily always less relevant. A smarter approach would be first to assess whether the new value 𝒗t\bm{v}_{t} overlaps with historical information, erase the overlapping parts accordingly, and then write the new value into memory. This strategy, referred to as the delta rule, is precisely the memory update mechanism employed by DeltaNet.

Inspired by the discussion above, _can we propose a new associative memory model that integrates the advantages of both the kernel trick and the delta rule?_ Such a model would achieve more intelligent memory update management while simultaneously ensuring high memory recall accuracy.

To achieve it, a straightforward approach is to introduce the delta rule into softmax attention. As shown in Table 2, the core of the delta rule is the decay term 𝑰−𝒌​𝒌⊤\bm{I}-\bm{k}\bm{k}^{\top} in the recurrent form. Thus, replacing 𝑩t\bm{B}_{t} in the recurrent form of softmax attention and incorporating the kernel trick would successfully introduce the delta rule into softmax attention:

##### General Form.

We can actually build the new model in a more general form by modifying the following components:

  * •

_Kernel function._ The kernel functions used for computing 𝒖\bm{u} (Eq. 39) and for memory retrieval (Eq. 40) need not be identical; different kernels can be adopted independently.

  * •

_Gate._ Gates can be introduced separately into the two parts of computing 𝒖\bm{u} (Eq. 39): the term −∑i=1t−1ϕ​(𝒌i)⊤​ϕ​(𝒌t)​𝒖i-\sum_{i=1}^{t-1}\phi(\bm{k}_{i})^{\top}\phi(\bm{k}_{t})\bm{u}_{i} and the vector 𝒗t\bm{v}_{t}.

  * •

In summary, the general form of the new model can be written as:

##### Model Expressivity.

Intuitively, neural networks can be viewed as circuits. Their expressivity can be measured via circuit complexity. Circuit complexity studies the minimal circuit size or depth required to solve computational problems, thus characterizing the intrinsic computational difficulty involved.

If we identify the circuit complexity corresponding to a given neural network, we can determine the class of computational problems that the network can solve, thereby characterizing its expressivity.

Circuit complexity typically focuses on Boolean circuits. A Boolean circuit is a directed acyclic graph composed of logic gates. It is defined by four parameters: 1) size, the total number of gates in the circuit; 2) depth, the number of gates along the longest path from input to output; 3) fan-in, the maximum number of inputs each gate can accept (either constant or unlimited); and 4) gate types: commonly AND, OR, NOT gates.

Depending on various combinations of these parameters, circuits are usually classified into three categories: N​CNC (Nick’s Class), A​CAC (Alternating Class), and T​CTC (Threshold Class). Circuit depth characterizes parallelism 101010Intuitively, for a circuit with a single layer, the output can be computed in one step. However, if the circuit has kk layers, it requires kk sequential steps to obtain the output. This implies that the number of circuit layers is inversely related to the degree of parallelism. and is important. It is explicitly indicated by a superscript kk. For example, N​CkNC^{k} denotes circuits of depth 𝒪​(logk⁡(n))\mathcal{O}(\log^{k}(n)), where nn is the input length.

We provide formal definitions of these three circuit classes:

  * •

_N ​CkNC^{k}_. Circuits with polynomial size in nn and depth 𝒪​(logk⁡(n))\mathcal{O}(\log^{k}(n)), using AND, OR, NOT gates with bounded fan-in (typically limited to 2 or a finite constant). Intuitively, this is analogous to hiring numerous workers to perform tasks in parallel, but each worker handles only a limited number of tasks at once (small fan-in). Classical computational problems solvable by N​CNC circuits include integer addition (k=1k=1) and matrix multiplication (k=2k=2).

  * •

_A ​CkAC^{k}_. Circuits with polynomial size in nn, depth 𝒪​(logk⁡(n))\mathcal{O}(\log^{k}(n)), and unlimited fan-in gates (AND, OR, NOT). Intuitively, this corresponds to hiring fewer but more powerful workers, each capable of processing numerous tasks simultaneously (unlimited fan-in). These circuits can perform simple logical judgments like “does at least one input equal 1?” or “do all inputs equal 1?” within constant depth, requiring infinite fan-in to achieve these computations efficiently.

  * •

_T ​CkTC^{k}_. Circuits with polynomial size in nn and depth 𝒪​(logk⁡(n))\mathcal{O}(\log^{k}(n)), employing special threshold gates. A threshold gate counts the number of inputs equal to 1, outputting 1 if this count meets or exceeds a certain threshold, and 0 otherwise. Threshold gates have unlimited fan-in. Intuitively, these circuits are more powerful, enabling efficient "majority voting" and thus handling more complex counting and decision tasks. Classical problems solvable by T​CTC circuits include numerical comparison, counting, and majority determination.

Figure 1: The hierarchical relationship among different circuit classes. The complexity of problems solvable by the three circuit classes N​CNC, A​CAC, and T​CTC is contained within PP. Specifically, we have: N​C0⊂A​C0⊂T​C0⊆N​C1⊆A​C1⊆T​C1⊆N​C2⊆⋯⊆P.NC^{0}\subset AC^{0}\subset TC^{0}\subseteq NC^{1}\subseteq AC^{1}\subseteq TC^{1}\subseteq NC^{2}\subseteq\cdots\subseteq P.

Due to the difference in fan-in restrictions (unlimited fan-in in A​CAC versus limited fan-in in N​CNC) and the more expressive threshold gates in T​CTC as compared to A​CAC, we arrive at the following hierarchy among the three circuit classes (Also demonstrated in Figure 1.):

| N​C0⊂A​C0⊂T​C0⊆N​C1⊆A​C1⊆T​C1⊆N​C2⊆⋯⊆P.\displaystyle NC^{0}\subset AC^{0}\subset TC^{0}\subseteq NC^{1}\subseteq AC^{1}\subseteq TC^{1}\subseteq NC^{2}\subseteq\cdots\subseteq P. |  | (43)  
---|---|---|---  
  
To gain intuitive clarity about the relationships between these three circuit classes, consider two illustrative examples:

  * •

_A ​C0AC^{0} vs. T​C0TC^{0}: Can we compute the sum of nn numbers in a single step?_ Despite unlimited fan-in, A​C0AC^{0} can only perform simple logical checks, such as "is at least one input equal to 1?", yet it cannot directly count how many inputs equal 1. Hence, A​C0AC^{0} cannot compute the sum of nn numbers in a single step. In contrast, T​C0TC^{0} introduces threshold gates, enabling counting of many bits (0 or 1) within constant depth, thus allowing summation of multiple numbers in a single (constant-depth) step.

  * •

_T ​C0TC^{0} vs. N​C1NC^{1}: Can we perform arbitrary swaps within a sequence of arbitrary length?_ A key limitation of T​C0TC^{0} is its constant depth: each output can only depend on information within a constant-sized neighborhood of the input, making arbitrary-length element swaps impossible. Conversely, N​C1NC^{1} circuits have logarithmic depth, allowing the construction of a binary-tree structure to perform swaps over arbitrary lengths efficiently.

So, what is the circuit complexity corresponding to the Transformer? Given sequence length nn, Merrill and Sabharwal [23] have shown that a constant-depth Transformer without chain-of-thought reasoning can only solve problems within T​C0TC^{0}. Meanwhile, several recent works [13, 38, 24] demonstrate that the expressivity of DeltaNet exceeds T​C0TC^{0}.

By proving that DeltaFormer proposed in this section can perform tracking of nn elements 111111Tracking nn states essentially refers to the task of swapping elements within a sequence of length nn., for n≥5n\geq 5 (see Appendix 10 for details), _the expressivity of DeltaFormer surpasses T​C0TC^{0} and theoretically reaches N​C1NC^{1}._

##### Algorithm Implementation.

We begin by analyzing the algorithm’s complexity. Let vectors 𝒒,𝒌,𝒗,𝒖∈ℝd\bm{q},\bm{k},\bm{v},\bm{u}\in\mathbb{R}^{d} 121212For the inner product, 𝒒\bm{q} and 𝒌\bm{k} must have the same dimension. Eq. 39 implies that 𝒗\bm{v} and 𝒖\bm{u} also share the same dimension. Although the dimensions of 𝒌\bm{k} and 𝒗\bm{v} may differ, this variance is generally bounded by a constant factor. For simplicity, we assume their dimensions are equal herein., and TT be the sequence length.

  * •

_Training phase._ First, we compute the sequence {𝒖}i=1T\\{\bm{u}\\}_{i=1}^{T}. Observing Eq. 39, the computational complexity 131313Computational complexity is defined here as the number of multiplication operations. for each 𝒖\bm{u} is 𝒪​(T​d)\mathcal{O}(Td). Thus, the computational complexity for the entire sequence amounts to 𝒪​(T2​d)\mathcal{O}(T^{2}d). Since 𝒖t\bm{u}_{t} depends on the history {𝒖}i=1t−1\\{\bm{u}\\}_{i=1}^{t-1}, the sequential time complexity is 𝒪​(T)\mathcal{O}(T). Once {𝒖}i=1T\\{\bm{u}\\}_{i=1}^{T} is computed, the operations in Eq. 40 incur computational and time complexities of 𝒪​(T2​d)\mathcal{O}(T^{2}d) and 𝒪​(1)\mathcal{O}(1), respectively. Therefore, the overall computational and time complexities during training are 𝒪​(T2​d)\mathcal{O}(T^{2}d) and 𝒪​(T)\mathcal{O}(T), respectively.

  * •

_Inference phase._ First, we compute 𝒖t\bm{u}_{t} and integrate it with 𝒌t\bm{k}_{t} to update 𝑺t\bm{S}_{t}. The corresponding computational and time complexities are 𝒪​(T​d)\mathcal{O}(Td) and 𝒪​(1)\mathcal{O}(1), respectively. Then, 𝒒t\bm{q}_{t} is employed to recall the final output 𝒐t\bm{o}_{t} from 𝑺t\bm{S}_{t}, with computational and time complexities of 𝒪​(d2)\mathcal{O}(d^{2}) and 𝒪​(1)\mathcal{O}(1), respectively. Consequently, the overall computational and time complexities during inference are 𝒪​(T​d+d2)\mathcal{O}(Td+d^{2}) and 𝒪​(1)\mathcal{O}(1), respectively.

According to the above analysis, the training-stage time complexity of 𝒪​(T)\mathcal{O}(T) is significantly worse than the 𝒪​(1)\mathcal{O}(1) complexity of softmax attention. Thus, improving training parallelism is crucial. To address this, we can partition the sequence into chunks and aim for fully parallel computation within each chunk. Consequently, the overall training time complexity can be optimized to 𝒪​(T/C)\mathcal{O}(T/C), where CC denotes the chunk size. ####  2.2.2 Vignette 3: What Will Happen in Infinitely Long In-Context Learning?

As shown in Table 2, different associative memory models correspond to distinct memory update optimization objectives. Taking the softmax attention as an example, during test-time decoding—i.e., in-context learning (ICL)—the corresponding memory 𝑺\bm{S} undergoes single-step gradient descent updates. Consider an extreme scenario: _as the length of ICL extends indefinitely, what would be the behavior of the entire optimization process?_ Exploring this limiting case may provide insights into predicting the technological evolution of models designed for extremely long contexts.

##### Single-head DeltaNet.

Specifically, we first consider a representative simple model: DeltaNet with single-head attention 141414The optimization objective corresponding to vanilla linear attention is unbounded. As tt increases, the norm of 𝑺​𝒌\bm{Sk} explodes, causing model collapse. This implies that linear attention (without optimizations such as memory decay) cannot perform very long in-context learning. The optimization objective for DeltaNet is bounded, avoiding the aforementioned issues, making it a more reasonable starting point for analysis and comparison.. The optimization objective of DeltaNet is:

| ℒt​(𝑺t−1)=12​‖𝑺t−1​𝒌t−𝒗t‖2.\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{2}\|\bm{S}_{t-1}\bm{k}_{t}-\bm{v}_{t}\|^{2}. |  | (44)

##### Softmax Attention.

Given that the multi-head structure can prevent ICL degradation, does this mean there are no theoretical obstacles remaining in constructing models supporting infinite context lengths? At least for softmax attention, this is not the case.

According to Table 2, the optimization objective of softmax attention is:

| ℒt​(𝑺t−1)=1t​(12​‖𝑺t−1‖F2−⟨𝑺t−1​ϕ​(𝒌t),𝒗t⟩).\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{t}\left(\frac{1}{2}\|\bm{S}_{t-1}\|^{2}_{F}-\langle\bm{S}_{t-1}\phi(\bm{k}_{t}),\bm{v}_{t}\rangle\right). |  | (49)

If we remove the normalization, although the gradient does not vanish as tt increases, softmax attention without normalization corresponds to an unbounded optimization objective, which would eventually lead to model collapse.

##### Summary.

Associative memory models theoretically risk converging gradually toward a fixed value as sequence length increases. Specifically for the attention layer, memory tends to progressively stop updating, leading to degraded ICL capability. Hence, _constructing models capable of infinite contexts may be challenging_. But it should be acknowledged that practical scenarios are considerably more complex: mechanisms such as multi-head attention, memory decay, and short key-value convolutions can effectively prevent memory updates from stagnating. Moreover, large neural networks typically exhibit multi-layered structures, where fluctuations in single-layer optimization (e.g., variability introduced by 𝔼𝒙​[𝒙​𝒙⊤]\mathbb{E}_{\bm{x}}[\bm{x}\bm{x}^{\top}]) may accumulate and amplify across layers, thus obstructing memory from smoothly approaching the theoretical analytical solution.

##  4 Conclusion

This exploration, viewing Transformers through the prism of associative memory, represents but a modest step in our ongoing quest to unravel the full potential and intricate workings of these powerful architectures. While we believe this perspective offers valuable clarity and a unifying framework for understanding phenomena like memory capacity and update dynamics, it simultaneously opens the door to a landscape teeming with further questions and avenues for deeper investigation. We find ourselves particularly intrigued by, and eager to further explore, the following fundamental inquiries:

The Architectural Endgame: Is there an ultimate, optimal design for model architectures? Is associative memory, as we’ve discussed it, the most effective paradigm for achieving artificial intelligence? If this framework is indeed central, are our current Transformer structures—with their distinct attention and feed-forward layers—approaching a fundamental optimum, or are there radically different, yet more potent, instantiations of associative memory waiting to be discovered?

Bridging Contextual and Persistent Memory: Why do current Transformers necessitate a separation between dynamic Context Memory (Attention) and static Persistent Memory (FFNs)? Human cognition features sophisticated mechanisms, like the role of the hippocampus, for filtering, consolidating, and transferring salient contextual experiences into long-term, persistent knowledge. When might our models acquire analogous capabilities? Such an advancement could allow them to learn continuously and adaptively during test time, potentially mitigating the challenges posed by infinitely long contexts. A critical sub-question here is: if such a consolidation mechanism were to be developed, what would be the intrinsic reward signal or loss function to guide its learning and refinement?

Parallelism, Hardware, and the Next Leap in Intelligence: The inherent parallel complexity of existing Transformer models (largely within T​C0TC^{0}) imposes limits on the types of problems they can efficiently learn and solve. This limitation is intrinsically linked to the capabilities of our current parallel hardware. Is there significant merit in pursuing models with higher parallel complexity classes (e.g., T​C1TC^{1} or even P-complete tasks)? Does the advent of next-generation intelligence hinge upon a paradigm shift in hardware—perhaps the maturation of technologies like quantum computing, which theoretically promise efficient solutions to problems currently intractable within T​CkTC^{k}?

These questions underscore the vast and fertile ground that still lies before us. The journey to understand and replicate intelligence is far from over. Each answer we find tends to illuminate a dozen new questions, each more profound than the last. It is our hope that by posing these challenges and sharing our current understanding, we can stimulate further discussion, collaboration, and innovation within the research community, collectively pushing the boundaries of what artificial intelligence can achieve. The path ahead is complex, but the pursuit of these fundamental questions promises a future rich with discovery.

##  7 Optimization Objective of Associative Memory

###  7.1 General Form

Consider a general recurrent form of memory update:

| 𝑺t=𝑨t​𝑺t−1​𝑩t+𝑪t,\displaystyle\bm{S}_{t}=\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t}+\bm{C}_{t}, |  | (59)  
---|---|---|---  
  
where 𝑨t\bm{A}_{t}, 𝑩t\bm{B}_{t}, and 𝑪t\bm{C}_{t} are parameter matrices.

We aim to construct a scalar optimization objective ℒt​(𝑺t−1)\mathcal{L}_{t}(\bm{S}_{t-1}) such that:

| 𝑺t=𝑺t−1−∂ℒt​(𝑺t−1)∂𝑺t−1.\displaystyle\bm{S}_{t}=\bm{S}_{t-1}-\frac{\partial\mathcal{L}_{t}(\bm{S}_{t-1})}{\partial\bm{S}_{t-1}}. |  | (60)  
---|---|---|---  
  
In other words, we require:

| ∂ℒt​(𝑺t−1)∂𝑺t−1=𝑺t−1−𝑨t​𝑺t−1​𝑩t−𝑪t.\displaystyle\frac{\partial\mathcal{L}_{t}(\bm{S}_{t-1})}{\partial\bm{S}_{t-1}}=\bm{S}_{t-1}-\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t}-\bm{C}_{t}. |  | (61)  
---|---|---|---  
  
The linear portion of this gradient field can be expressed as:

| 𝑺t−1↦𝑺t−1−𝑨t​𝑺t−1​𝑩t.\displaystyle\bm{S}_{t-1}\mapsto\bm{S}_{t-1}-\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t}. |  | (62)  
---|---|---|---  
  
To ensure that a vector field is a valid gradient field in matrix space (equipped with the Frobenius inner product ⟨𝑿,𝒀⟩=tr​(𝑿⊤​𝒀)\langle\bm{X},\bm{Y}\rangle=\mathrm{tr}(\bm{X}^{\top}\bm{Y})), it must be self-adjoint. Specifically, for arbitrary matrices 𝑿,𝒀\bm{X},\bm{Y}, we need:

| ⟨𝑿,𝑨t​𝒀​𝑩t⟩=⟨𝑨t​𝑿​𝑩t,𝒀⟩.\displaystyle\langle\bm{X},\bm{A}_{t}\bm{Y}\bm{B}_{t}\rangle=\langle\bm{A}_{t}\bm{X}\bm{B}_{t},\bm{Y}\rangle. |  | (63)  
---|---|---|---  
  
This condition requires 𝑨t\bm{A}_{t} and 𝑩t\bm{B}_{t} to be symmetric matrices. If they are not symmetric, generally there does not exist a scalar potential function whose gradient yields the desired vector field (Eq. 62).

Assuming that 𝑨t\bm{A}_{t} and 𝑩t\bm{B}_{t} are symmetric, we can explicitly construct ℒt​(𝑺t−1)\mathcal{L}_{t}(\bm{S}_{t-1}) as follows:

| ℒt​(𝑺t−1)=12​tr⁡(𝑺t−1⊤​𝑺t−1)−12​tr⁡(𝑺t−1⊤​𝑨t​𝑺t−1​𝑩t)−tr⁡(𝑪t⊤​𝑺t−1),\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{2}\operatorname{tr}(\bm{S}_{t-1}^{\top}\bm{S}_{t-1})-\frac{1}{2}\operatorname{tr}(\bm{S}_{t-1}^{\top}\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t})-\operatorname{tr}(\bm{C}_{t}^{\top}\bm{S}_{t-1}), |  | (64)  
---|---|---|---  
  
where the gradient of each term is:

  * •

gradient of the first term:

| ∂∂𝑺t−1​12​tr​(𝑺t−1⊤​𝑺t−1)=𝑺t−1;\frac{\partial}{\partial\bm{S}_{t-1}}\frac{1}{2}\mathrm{tr}(\bm{S}_{t-1}^{\top}\bm{S}_{t-1})=\bm{S}_{t-1}; |   
---|---|---  
  
  * •

gradient of the second term (assuming symmetric 𝑨t\bm{A}_{t} and 𝑩t\bm{B}_{t}):

| ∂∂𝑺t−1​12​tr​(𝑺t−1⊤​𝑨t​𝑺t−1​𝑩t)=𝑨t​𝑺t−1​𝑩t;\frac{\partial}{\partial\bm{S}_{t-1}}\frac{1}{2}\mathrm{tr}(\bm{S}_{t-1}^{\top}\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t})=\bm{A}_{t}\bm{S}_{t-1}\bm{B}_{t}; |   
---|---|---  
  
  * •

gradient of the third term:

| ∂∂𝑺t−1​tr​(𝑪t⊤​𝑺t−1)=𝑪t.\frac{\partial}{\partial\bm{S}_{t-1}}\mathrm{tr}(\bm{C}_{t}^{\top}\bm{S}_{t-1})=\bm{C}_{t}. |   
---|---|---

we obtain: 𝑨t=𝑰\bm{A}_{t}=\bm{I}, 𝑩t=𝑰−𝒌t​𝒌t⊤\bm{B}_{t}=\bm{I}-\bm{k}_{t}\bm{k}_{t}^{\top}, and 𝑪t=𝒗t​𝒌t⊤\bm{C}_{t}=\bm{v}_{t}\bm{k}_{t}^{\top}. Substituting these into Eq. 64, we have:

| ℒt​(𝑺t−1)=12​tr⁡(𝑺t−1⊤​𝑺t−1​𝒌t​𝒌t⊤)−tr⁡(𝒌t​𝒗t⊤​𝑺t−1),\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{2}\operatorname{tr}(\bm{S}_{t-1}^{\top}\bm{S}_{t-1}\bm{k}_{t}\bm{k}_{t}^{\top})-\operatorname{tr}(\bm{k}_{t}\bm{v}_{t}^{\top}\bm{S}_{t-1}), |  | (71)  
---|---|---|---  
  
where

| tr⁡(𝑺t−1⊤​𝑺t−1​𝒌t​𝒌t⊤)\displaystyle\operatorname{tr}(\bm{S}_{t-1}^{\top}\bm{S}_{t-1}\bm{k}_{t}\bm{k}_{t}^{\top}) | =tr⁡((𝑺t−1​𝒌t)​(𝑺t−1​𝒌t)⊤)\displaystyle=\operatorname{tr}((\bm{S}_{t-1}\bm{k}_{t})(\bm{S}_{t-1}\bm{k}_{t})^{\top}) |   
---|---|---|---  
|  | =‖𝑺t−1​𝒌t‖2.\displaystyle=\|\bm{S}_{t-1}\bm{k}_{t}\|^{2}. |  | (72)  
  
Thus,

| ℒt​(𝑺t−1)\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1}) | =12​‖𝑺t−1​𝒌t‖2−⟨𝑺t−1​𝒌t,𝒗t⟩\displaystyle=\frac{1}{2}\|\bm{S}_{t-1}\bm{k}_{t}\|^{2}-\langle\bm{S}_{t-1}\bm{k}_{t},\bm{v}_{t}\rangle |   
---|---|---|---  
|  | =12​‖𝑺t−1​𝒌t−𝒗t‖2−12​‖𝒗t‖2.\displaystyle=\frac{1}{2}\|\bm{S}_{t-1}\bm{k}_{t}-\bm{v}_{t}\|^{2}-\frac{1}{2}\|\bm{v}_{t}\|^{2}. |  | (73)  
  
Since −12​‖𝒗t‖2-\frac{1}{2}\|\bm{v}_{t}\|^{2} is independent of 𝑺t−1\bm{S}_{t-1} and thus vanishes after taking the gradient, the optimization objective can be expressed as:

| ℒt​(𝑺t−1)=12​‖𝑺t−1​𝒌t−𝒗t‖2.\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{2}\|\bm{S}_{t-1}\bm{k}_{t}-\bm{v}_{t}\|^{2}. |  | (74)  
---|---|---|---  
  
Introducing momentum, i.e., 𝑪t=ηt​𝑪t−1+𝒗t​𝒌t⊤\bm{C}_{t}=\eta_{t}\bm{C}_{t-1}+\bm{v}_{t}\bm{k}_{t}^{\top}, where η\eta is the momentum coefficient and η∈(0,1)\eta\in(0,1), we expand this recurrent formulation as follows:

| 𝑪t=∑i=1t(∏j=i+1tηj)​𝒗i​𝒌i⊤.\displaystyle\bm{C}_{t}=\sum_{i=1}^{t}\left(\prod_{j=i+1}^{t}\eta_{j}\right)\bm{v}_{i}\bm{k}_{i}^{\top}. |  | (75)  
---|---|---|---  
  
This corresponds to adding an extra constant-coefficient term to the original 𝑪t\bm{C}_{t}, updating the optimization objective to:

| ℒt​(𝑺t−1)=12​‖𝑺t−1​𝒌t‖2−∑i=1t(∏j=i+1tηj)​⟨𝑺t−1​𝒌t,𝒗t⟩.\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{2}\|\bm{S}_{t-1}\bm{k}_{t}\|^{2}-\sum_{i=1}^{t}\left(\prod_{j=i+1}^{t}\eta_{j}\right)\langle\bm{S}_{t-1}\bm{k}_{t},\bm{v}_{t}\rangle. |  | (76)

##### Softmax Attention

Consider the output 𝒐t\bm{o}_{t}:

| 𝒐t\displaystyle\bm{o}_{t} | =∑i=1texp⁡(𝒒t⊤​𝒌i)∑j=1texp⁡(𝒒t⊤​𝒌j)​𝒗i\displaystyle=\sum_{i=1}^{t}\frac{\exp(\bm{q}_{t}^{\top}\bm{k}_{i})}{\sum_{j=1}^{t}\exp(\bm{q}_{t}^{\top}\bm{k}_{j})}\bm{v}_{i} |   
---|---|---|---  
|  | =∑i=1tϕ​(𝒒t)⊤​ϕ​(𝒌i)∑j=1texp⁡(𝒒t⊤​𝒌j)​𝒗i,\displaystyle=\sum_{i=1}^{t}\frac{\phi(\bm{q}_{t})^{\top}\phi(\bm{k}_{i})}{\sum_{j=1}^{t}\exp(\bm{q}_{t}^{\top}\bm{k}_{j})}\bm{v}_{i}, |  | (77)  
  
where ϕ​(⋅)\phi(\cdot) is defined by Eq. 11. For sufficiently large tt, according to the law of large numbers, we have ∑j=1texp⁡(𝒒t⊤​𝒌j)≈t​c​(𝒒t)\sum_{j=1}^{t}\exp(\bm{q}_{t}^{\top}\bm{k}_{j})\approx tc(\bm{q}_{t}), where c​(𝒒t)c(\bm{q}_{t}) is a query-specific constant. Thus, the output can be approximated as:

| 𝒐t≈1c​(𝒒t)​∑i=1tϕ​(𝒒t)⊤​ϕ​(𝒌i)t​𝒗i.\displaystyle\bm{o}_{t}\approx\frac{1}{c(\bm{q}_{t})}\sum_{i=1}^{t}\frac{\phi(\bm{q}_{t})^{\top}\phi(\bm{k}_{i})}{t}\bm{v}_{i}. |  | (78)  
---|---|---|---  
  
Let 𝑺t=∑i=1t𝒗i​ϕ​(𝒌i)⊤t\bm{S}_{t}=\sum_{i=1}^{t}\frac{\bm{v}_{i}\phi(\bm{k}_{i})^{\top}}{t}; then we have:

| 𝑺t=t−1t​𝑺t−1+1t​𝒗t​ϕ​(𝒌t)⊤.\displaystyle\bm{S}_{t}=\frac{t-1}{t}\bm{S}_{t-1}+\frac{1}{t}\bm{v}_{t}\phi(\bm{k}_{t})^{\top}. |  | (79)  
---|---|---|---  
  
This implies that 𝑨t=t−1t​𝑰\bm{A}_{t}=\frac{t-1}{t}\bm{I}, 𝑩t=𝑰\bm{B}_{t}=\bm{I}, and 𝑪t=1t​𝒗t​ϕ​(𝒌t)⊤\bm{C}_{t}=\frac{1}{t}\bm{v}_{t}\phi(\bm{k}_{t})^{\top}. Substituting these into Eq. 64, we obtain:

| ℒt​(𝑺t−1)=1t​(12​‖𝑺t−1‖F2−⟨𝑺t−1​ϕ​(𝒌t),𝒗t⟩).\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{t}\left(\frac{1}{2}\|\bm{S}_{t-1}\|_{F}^{2}-\langle\bm{S}_{t-1}\phi(\bm{k}_{t}),\bm{v}_{t}\rangle\right). |  | (80)

If we introduce the gating matrix diag​(𝝀t)\text{diag}(\bm{\lambda}_{t}), i.e., 𝑨t=t−1t​diag​(𝝀t)\bm{A}_{t}=\frac{t-1}{t}\text{diag}(\bm{\lambda}_{t}), then:

| ℒt​(𝑺t−1)=1t​(12​diag​(1−𝝀t)​‖𝑺t−1‖F2−⟨𝑺t−1​ϕ​(𝒌t),𝒗t⟩).\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{t}\left(\frac{1}{2}\text{diag}(1-\bm{\lambda}_{t})\|\bm{S}_{t-1}\|_{F}^{2}-\langle\bm{S}_{t-1}\phi(\bm{k}_{t}),\bm{v}_{t}\rangle\right). |  | (81)

##  8 Delta Rule with Kernel Function

We consider the kernel function κ​(𝒙,𝒚)=f​(𝒙)⊤​f​(𝒚)\kappa(\bm{x},\bm{y})=f(\bm{x})^{\top}f(\bm{y}), where f​(𝒙)f(\bm{x}) is a mapping from dd to infinite dimensions. Then the delta-rule-based update form and the corresponding read-out equation can be re-write as:

| 𝑺t\displaystyle\bm{S}_{t} | =𝑺t−1​(𝑰−f​(𝒌t)​f​(𝒌t)⊤)+𝒗t​f​(𝒌t)⊤,\displaystyle=\bm{S}_{t-1}{\left(\bm{I}-f(\bm{k}_{t})f(\bm{k}_{t})^{\top}\right)}+\bm{v}_{t}f(\bm{k}_{t})^{\top}, |  | (82)  
---|---|---|---|---  
| 𝒐t\displaystyle\bm{o}_{t} | =𝑺t​f​(𝒒t).\displaystyle={\bm{S}_{t}f(\bm{q}_{t})}. |  | (83)  
  
Hypothesis:

| 𝑺t=∑i=1t𝒖i​𝒘i⊤,\displaystyle\bm{S}_{t}=\sum_{i=1}^{t}\bm{u}_{i}\bm{w}_{i}^{\top}, |  | (84)  
---|---|---|---  
  
where 𝒖i\bm{u}_{i} and 𝒘i\bm{w}_{i} is pending. Then we have:

| ∑i=1t𝒖i​𝒘i⊤\displaystyle\sum_{i=1}^{t}\bm{u}_{i}\bm{w}_{i}^{\top} | =∑i=1t−1𝒖i​𝒘i⊤​(𝑰−f​(𝒌t)​f​(𝒌t)⊤)+𝒗t​f​(𝒌t)⊤,\displaystyle=\sum_{i=1}^{t-1}\bm{u}_{i}\bm{w}_{i}^{\top}{\left({\bm{I}}-f(\bm{k}_{t})f(\bm{k}_{t})^{\top}\right)}+\bm{v}_{t}f(\bm{k}_{t})^{\top}, |  | (85)  
---|---|---|---|---  
| 𝒖t​𝒘t⊤\displaystyle\bm{u}_{t}\bm{w}_{t}^{\top} | =∑i=1t−1𝒖i​𝒘i⊤​(−f​(𝒌t)​f​(𝒌t)⊤)+𝒗t​f​(𝒌t)⊤,\displaystyle=\sum_{i=1}^{t-1}\bm{u}_{i}\bm{w}_{i}^{\top}{\left(-f(\bm{k}_{t})f(\bm{k}_{t})^{\top}\right)}+\bm{v}_{t}f(\bm{k}_{t})^{\top}, |  | (86)  
  
take the pending 𝒘i=f​(𝒌i)\bm{w}_{i}=f(\bm{k}_{i}):

| 𝒖t​f​(𝒌t)⊤\displaystyle\bm{u}_{t}f(\bm{k}_{t})^{\top} | =∑i=1t−1𝒖i​f​(𝒌i)⊤​(−f​(𝒌t)​f​(𝒌t)⊤)+𝒗t​f​(𝒌t)⊤\displaystyle=\sum_{i=1}^{t-1}\bm{u}_{i}f(\bm{k}_{i})^{\top}{\left(-f(\bm{k}_{t})f(\bm{k}_{t})^{\top}\right)}+\bm{v}_{t}f(\bm{k}_{t})^{\top} |   
---|---|---|---  
|  | =−∑i=1t−1f​(𝒌i)⊤​f​(𝒌t)​𝒖i​f​(𝒌t)⊤+𝒗t​f​(𝒌t)⊤\displaystyle=-\sum_{i=1}^{t-1}f(\bm{k}_{i})^{\top}f(\bm{k}_{t})\bm{u}_{i}f(\bm{k}_{t})^{\top}+\bm{v}_{t}f(\bm{k}_{t})^{\top} |   
|  | =(−∑i=1t−1f​(𝒌i)⊤​f​(𝒌t)​𝒖i+𝒗t)​f​(𝒌t)⊤.\displaystyle=\left(-\sum_{i=1}^{t-1}f(\bm{k}_{i})^{\top}f(\bm{k}_{t})\bm{u}_{i}+\bm{v}_{t}\right)f(\bm{k}_{t})^{\top}. |  | (87)  
  
Thus, we get the pending 𝒖t\bm{u}_{t}:

| 𝒖t​f​(𝒌t)⊤\displaystyle\bm{u}_{t}\bcancel{f(\bm{k}_{t})^{\top}} | =(−∑i=1t−1f​(𝒌i)⊤​f​(𝒌t)​𝒖i+𝒗t)​f​(𝒌t)⊤\displaystyle=\left(-\sum_{i=1}^{t-1}f(\bm{k}_{i})^{\top}f(\bm{k}_{t})\bm{u}_{i}+\bm{v}_{t}\right)\bcancel{f(\bm{k}_{t})^{\top}} |   
---|---|---|---  
|  | =−∑i=1t−1κ​(𝒌i,𝒌t)​𝒖i+𝒗t.\displaystyle=-\sum_{i=1}^{t-1}\kappa(\bm{k}_{i},\bm{k}_{t})\bm{u}_{i}+\bm{v}_{t}. |  | (88)  
  
Then we have the final update form and the corresponding read-out equation:

| 𝑺t\displaystyle\bm{S}_{t} | =∑i=1t𝒖i​f​(𝒌i)⊤=𝑺t−1+𝒖t​ϕ​(𝒌t)⊤,\displaystyle=\sum_{i=1}^{t}\bm{u}_{i}f(\bm{k}_{i})^{\top}=\bm{S}_{t-1}+\bm{u}_{t}\phi(\bm{k}_{t})^{\top}, |  | (89)  
---|---|---|---|---  
| 𝒐t\displaystyle\bm{o}_{t} | =∑i=1tκ​(𝒌i,𝒒t)​𝒖i.\displaystyle=\sum_{i=1}^{t}\kappa(\bm{k}_{i},\bm{q}_{t})\bm{u}_{i}. |  | (90)  
  
##  9 Re-examining DeltaNet from the Perspective of Information Aggregation

In this section, we present our initial motivation and derivation for the combination of DeltaNet [33, 48] and softmax attention. But this differs significantly from the narrative logic in the main text and maybe not as easy to understand as the main text, so it is included in the appendix.

###  9.1 Information Aggregation

We first consider the vanilla Transformer attention. For simplicity, ignoring the exponential kernel and normalization term, the corresponding associative memory update is:

| 𝑺t=𝑺t−1+𝒗t​𝒌t⊤.\displaystyle\bm{S}_{t}=\bm{S}_{t-1}+\bm{v}_{t}\bm{k}_{t}^{\top}. |  | (91)  
---|---|---|---  
  
In this form, the stored information {𝒗1,𝒗2,…}\\{\bm{v}_{1},\bm{v}_{2},\dots\\} is independent across time steps and can be computed in parallel. Now, consider a new form of value representation 𝒖\bm{u} defined as:

| 𝒖t=𝒗t−∑i=1t−1(𝒌i⊤​𝒌t)​𝒖i.\displaystyle\bm{u}_{t}=\bm{v}_{t}-\sum_{i=1}^{t-1}(\bm{k}_{i}^{\top}\bm{k}_{t})\,\bm{u}_{i}. |  | (92)  
---|---|---|---  
  
In this case, the stored information {𝒖1,𝒖2,…}\\{\bm{u}_{1},\bm{u}_{2},\dots\\} is no longer independent but has a recurrent dependency structure. Consequently, the associative memory update becomes:

| 𝑺t\displaystyle\bm{S}_{t} | =𝑺t−1+𝒖t​𝒌t⊤\displaystyle=\bm{S}_{t-1}+\bm{u}_{t}\bm{k}_{t}^{\top} |   
---|---|---|---  
|  | =𝑺t−1+(𝒗t−∑i=1t−1(𝒌i⊤​𝒌t)​𝒖i)​𝒌t⊤\displaystyle=\bm{S}_{t-1}+\left(\bm{v}_{t}-\sum_{i=1}^{t-1}(\bm{k}_{i}^{\top}\bm{k}_{t})\,\bm{u}_{i}\right)\bm{k}_{t}^{\top} |   
|  | =𝑺t−1+(𝒗t−(∑i=1t−1𝒖i​𝒌i⊤)​𝒌t)​𝒌t⊤\displaystyle=\bm{S}_{t-1}+\left(\bm{v}_{t}-\left(\sum_{i=1}^{t-1}\bm{u}_{i}\bm{k}_{i}^{\top}\right)\bm{k}_{t}\right)\bm{k}_{t}^{\top} |   
|  | =𝑺t−1+(𝒗t−𝑺t−1​𝒌t)​𝒌t⊤\displaystyle=\bm{S}_{t-1}+\left(\bm{v}_{t}-\bm{S}_{t-1}\bm{k}_{t}\right)\bm{k}_{t}^{\top} |   
|  | =𝑺t−1​(𝑰−𝒌t​𝒌t⊤)+𝒗t​𝒌t⊤.\displaystyle=\bm{S}_{t-1}\left(\bm{I}-\bm{k}_{t}\bm{k}_{t}^{\top}\right)+\bm{v}_{t}\bm{k}_{t}^{\top}. |  | (93)  
  
Surprisingly, we find that this formulation recovers DeltaNet. We have derived DeltaNet from an alternative perspective. The information aggregation method in Eq. 92 essentially corresponds to DeltaNet.

Intuitively, vanilla attention simply writes each timestep’s value into memory. In contrast, the delta rule (Eq. 92) first removes redundant information from the current value based on key similarity with historical values, writing only incremental information. Thus, the latter aggregation mechanism supports both memory writing and deletion, whereas the former supports only writing.

###  9.2 Enhancing Retrieval Capability of DeltaNet

Further, we can enhance the information retrieval capability of vanilla DeltaNet by introducing kernel functions. Specifically, we replace the key similarity computation in Eq. 92 with an exponential kernel function:

| 𝒖t=𝒗t−∑i=1t−1exp⁡(𝒌i⊤​𝒌t)𝒁t(1)​𝒖i,\displaystyle\bm{u}_{t}=\bm{v}_{t}-\sum_{i=1}^{t-1}\frac{\exp(\bm{k}_{i}^{\top}\bm{k}_{t})}{\bm{Z}_{t}^{(1)}}\bm{u}_{i}, |  | (94)  
---|---|---|---  
  
where, similar to softmax attention, we introduce a normalization term 𝒁t(1)=∑i=1t−1exp⁡(𝒌i⊤​𝒌t)\bm{Z}_{t}^{(1)}=\sum_{i=1}^{t-1}\exp(\bm{k}_{i}^{\top}\bm{k}_{t}). Consequently, the current output 𝒐t\bm{o}_{t} is computed as:

| 𝒐t=∑i=1texp⁡(𝒌i⊤​𝒒t)𝒁t(2)​𝒖i,\displaystyle\bm{o}_{t}=\sum_{i=1}^{t}\frac{\exp(\bm{k}_{i}^{\top}\bm{q}_{t})}{\bm{Z}_{t}^{(2)}}\bm{u}_{i}, |  | (95)  
---|---|---|---  
  
where 𝒁t(2)=∑i=1texp⁡(𝒌i⊤​𝒒t)\bm{Z}_{t}^{(2)}=\sum_{i=1}^{t}\exp(\bm{k}_{i}^{\top}\bm{q}_{t}). Note that the normalization terms 𝒁t(1)\bm{Z}_{t}^{(1)} and 𝒁t(2)\bm{Z}_{t}^{(2)} could alternatively use RMSNorm [49] to stabilize training.

In summary, we successfully integrate the delta rule with softmax attention.

###  9.3 Efficient Chunk-wise Implementation

Consider 𝒒,𝒌,𝒗,𝒖∈ℝd\bm{q},\bm{k},\bm{v},\bm{u}\in\mathbb{R}^{d}, sequence length TT, and assume T≫dT\gg d. If we compute {𝒖1,…,𝒖T}\\{\bm{u}_{1},\dots,\bm{u}_{T}\\} according to Eq. 94, the computational complexity is 𝒪​(T2​d)\mathcal{O}(T^{2}d). Note that, since each 𝒖t\bm{u}_{t} depends on all previous 𝒖<t\bm{u}_{<t}, this algorithm cannot be parallelized, resulting in a training-time complexity of 𝒪​(T)\mathcal{O}(T), significantly slower than the 𝒪​(1)\mathcal{O}(1) complexity of standard softmax attention. Consequently, it fails to utilize GPUs’ parallel computation capabilities.

In fact, the computations of {𝒖1,…,𝒖T}\\{\bm{u}_{1},\dots,\bm{u}_{T}\\} can be parallelized at the cost of increased computes. Rewriting Eq. 94 in matrix form, we have:

| 𝑼=𝑽−𝑨​𝑼,\displaystyle\bm{U}=\bm{V}-\bm{A}\bm{U}, |  | (96)  
---|---|---|---  
  
where the tt-th rows of matrices 𝑼\bm{U} and 𝑽\bm{V} are 𝑼t,:=𝒖t\bm{U}_{t,:}=\bm{u}_{t} and 𝑽t,:=𝒗t\bm{V}_{t,:}=\bm{v}_{t}, respectively. The similarity matrix 𝑨\bm{A} is defined as 𝑨t,i=exp⁡(𝒌i⊤​𝒌t)𝒁t(1)\bm{A}_{t,i}=\frac{\exp(\bm{k}_{i}^{\top}\bm{k}_{t})}{\bm{Z}_{t}^{(1)}} and is lower-triangular. Thus, 𝑼\bm{U} can be solved via matrix operations:

| 𝑼=(𝑰+𝑨)−1​𝑽.\displaystyle\bm{U}=(\bm{I}+\bm{A})^{-1}\bm{V}. |  | (97)  
---|---|---|---  
  
This approach requires a matrix inversion operation, increasing computational complexity to 𝒪​(T3)\mathcal{O}(T^{3}), but can be paralleled in GPUs.

Intuitively, we can seek a trade-off between the two approaches described above. By dividing the sequence of length TT into NN equally sized chunks, each having length C=⌊TN⌋C=\lfloor\frac{T}{N}\rfloor, we can sequentially compute the sequence of 𝒖\bm{u} for each chunk using parallelized matrix operations. As a result, the recurrent steps from 𝒪​(T)\mathcal{O}(T) to 𝒪​(N)\mathcal{O}(N), while the computational complexity transitions from 𝒪​(T2​d)\mathcal{O}(T^{2}d) to 𝒪​(T2​d+T​C​d+T​C2)\mathcal{O}(T^{2}d+TCd+TC^{2}). Essentially, this approach trades computational resources for reduced runtime.

Below is a simple PyTorch implementation, serving as pseudo-code. We can easily modify the selection of the kernel function or remove the normalization term.

⬇

import torch

import torch.nn.functional as F

import math

def flash_attn(K_chunk, K_prev, V_prev):

attn = K_chunk @ K_prev.transpose(-1, -2)/math.sqrt(K_chunk.shape[-1])

z_intra = torch.logsumexp(attn, dim=-1)

return torch.softmax(attn,dim=-1)@V_prev, z_intra

def naive_implementation(k, n, d_model): """n is the previous v, v is actually new v. """

B, H, T, D = k.shape

v = torch.zeros_like(n)

for t in range(T):

if t == 0:

v[:, :, 0] = n[:, :, 0]

else:

scores = torch.matmul(k[:, :, :t], k[:, :, t].unsqueeze(-1)).squeeze(-1) / math.sqrt(d_model)

attn_probs = F.softmax(scores, dim=-1)

v[:, :, t] = n[:, :, t] - torch.sum(attn_probs.unsqueeze(-1) * v[:, :, :t], dim=-2)

return v

def optimized_chunked_implementation(K, N, d_model, C):

B, H, T, D = K.shape

V = torch.zeros(B, H, T, D)

chunk_nums = T // C

mask = torch.tril(torch.ones(C, C),diagonal=-1).unsqueeze(0).unsqueeze(0).to(K.device)

for chunk_num in range(chunk_nums):

start = chunk_num * C

end = (chunk_num + 1) * C

K_chunk = K[:, :, start:end]

N_chunk = N[:, :, start:end]

if chunk_num > 0:

intra_output, Z_intra = flash_attn(K_chunk, K[:, :, :start], V[:, :, :start])#\mathcal{O}(TCD)

A = (K_chunk @ K_chunk.transpose(-2, -1)).masked_fill(mask[:, :, :C, :C] == 0, float("-inf")) / math.sqrt(d_model)#\mathcal{O}(C^2D)

Z_inter = torch.logsumexp(A, dim=-1)

P = N_chunk - intra_output * (1/(1 + torch.exp((Z_inter-Z_intra).unsqueeze(-1))))

A = F.softmax(A, dim=-1) * (1/(1 + torch.exp((Z_intra-Z_inter).unsqueeze(-1))))

A[:,:,0,:] = 0

else:

A = (K_chunk @ K_chunk.transpose(-2, -1)).masked_fill(mask[:, :, :C, :C] == 0, float("-inf")) / math.sqrt(d_model)

A = F.softmax(A, dim=-1)

A[:,:,0,:] = 0

P = N_chunk

Ti = torch.eye(C).unsqueeze(0).unsqueeze(0).unsqueeze(0).to(K.device) + A

Ti_inverse = torch.inverse(Ti) ## Forward substitution method \mathcal{O}(C^3) Each block can be solved in parallel if we don’t use the normalization of softmax. To fully utilize GPUs, we can use \mathcal{O}(log C) iteration, each iteration use \mathcal{O}(C^3) flops, such as $a_1,b_1 = I - A, A^2$, $a_{i+1},b_{i+1} = a_{i}@b_{i} + b_{i}@b_{i}$, return a_{log C - 1}

V[:, :, start:end] = Ti_inverse @ P # \mathcal{O}(C^2D)

return V #\mathcal{O}(T/C * (TCD + C^2D)) = \mathcal{O}(T^2D + TCD + TC^2)

def verify_equivalence():

B = 2

H = 2

T = 1024

D = 64

For every α∈(0,1)\alpha\in(0,1) and ε>0\varepsilon>0, there exists c>0c>0 such that for every dd, one can find at least 2c​d2^{cd} unit vectors in ℝd\mathbb{R}^{d} whose pairwise inner products all lie in [α−ε,α+ε][\alpha-\varepsilon,\alpha+\varepsilon].

Under appropriate rounding precision, this function can satisfy the assumption. But it faces optimization problems that require careful design. Therefore, a natural idea is to use a combination of multiple easily optimized kernels to approximate the round kernel. Given the KU cache size, it is natural to think of using grouped-query attention (GQA) [1] to implement it, which is why we decouple 𝒌\bm{k} in κ1\kappa_{1} into 𝒘\bm{w} and 𝒌\bm{k} in the general form. After decoupling, 𝒘\bm{w} can use GQA to improve performance without increasing KU cache:

###  10.3 Stronger Compression Capability

What is the space cost in Theorem 1, if we want to track TT exchanges of nn states? Obviously, we need to set d=𝒪​(log⁡n)d=\mathcal{O}(\log n) and use KU cache with length TT. So it needs 𝒪​(T​log⁡n)\mathcal{O}(T\log n) spaces.

If we read out {𝒗~1,…,𝒗~n}\\{\tilde{\bm{v}}_{1},\dots,\tilde{\bm{v}}_{n}\\} based on {𝒌1,…,𝒌n}\\{\bm{k}_{1},\dots,\bm{k}_{n}\\} every 𝒪​(n)\mathcal{O}(n) steps, then re-write {(𝒌i,𝒗~i)}i=1n\\{(\bm{k}_{i},\tilde{\bm{v}}_{i})\\}_{i=1}^{n} into KU cache. We only use the KU cache with length 𝒪​(n)\mathcal{O}(n), so the total space cost is 𝒪​(n​log⁡n)\mathcal{O}(n\log n), which is much smaller than the 𝒪​(n2)\mathcal{O}(n^{2}) space when f​(⋅)f(\cdot) is an identity mapping, in which Peng et al. [26] use a 5×55\times 5 matrix to track the exchange of 55 elements.

For comparison, employing non-linear kernels unlocks the powerful potential of the delta rule: we can track the exchange of exponentially many states instead of merely the previous n=𝒪​(d)n=\mathcal{O}(d) states. Analogously, softmax attention can retrieve richer information from substantially longer contexts compared to linear attention.

class MultiHeadAttention(nn.Module):

def __init__(self, dim, num_q_heads=8, num_kv_heads=None, rotary_base=10000):

super().__init__()

self.num_q_heads = num_q_heads

self.num_kv_heads = num_kv_heads or num_q_heads # if None, full MHA

self.rotary_base = rotary_base

self.head_dim = dim // self.num_q_heads

self.q_proj = nn.Linear(dim, dim)

self.k_proj = nn.Linear(dim, self.head_dim * num_kv_heads)

self.v_proj = nn.Linear(dim, self.head_dim * num_kv_heads)

self.out = nn.Linear(dim, dim)

def forward(self, x):

b, t, d = x.size()

# project

q = self.q_proj(x).view(b, t, self.num_q_heads, self.head_dim).transpose(1, 2)

k = self.k_proj(x).view(b, t, self.num_kv_heads, self.head_dim).transpose(1, 2)

v = self.v_proj(x).view(b, t, self.num_kv_heads, self.head_dim).transpose(1, 2)

# compute attention scores: broadcast kv heads to q heads if needed

k_expanded = k.unsqueeze(2).expand(-1, -1, self.num_q_heads // self.num_kv_heads, -1, -1).reshape(b, -1, t, self.head_dim)

v_expanded = v.unsqueeze(2).expand(-1, -1, self.num_q_heads // self.num_kv_heads, -1, -1).reshape(b, -1, t, self.head_dim)

# q: b,t,Qh,hd, k_expanded: b,t,Qh,hd

scores = torch.einsum(’bhtd,bhsd->bhts’, q, k_expanded) / math.sqrt(d // self.num_q_heads)

attn_mask = torch.tril(torch.ones(t, t)).unsqueeze(0).unsqueeze(1).to(x.device)

scores = scores.masked_fill(attn_mask == 0, float(’-inf’))

attn = torch.softmax(scores, dim=-1).to(x.dtype)

out = torch.einsum(’bhts,bhsd->bthd’, attn, v_expanded)

out = out.reshape(b, t, d)

return self.out(out)

class DeltaAttention(MultiHeadAttention):

def __init__(self, dim, num_q_heads=8, num_kv_heads=None, rotary_base=10000, kernel_1=’linear’, kernel_2=’linear’):

super().__init__(dim, num_q_heads, num_kv_heads, rotary_base)

self.alpha = nn.Parameter(torch.ones(1), requires_grad=True)

self.beta = nn.Parameter(torch.ones(1), requires_grad=True)

self.kernel_1 = kernel_1

self.kernel_2 = kernel_2

self.w_proj = nn.Linear(dim, dim)

self.w_weight = nn.Parameter(torch.randn(1,num_q_heads,1,1), requires_grad=True)

def forward(self, x):

b, t, d = x.size()

# project

q = self.q_proj(x).view(b, t, self.num_q_heads, self.head_dim).transpose(1, 2)

w = self.w_proj(x).view(b, t, self.num_q_heads, self.head_dim).transpose(1, 2)

k = self.k_proj(x).view(b, t, self.num_kv_heads, self.head_dim).transpose(1, 2)

v = self.v_proj(x).view(b, t, self.num_kv_heads, self.head_dim).transpose(1, 2)

# compute attention scores: broadcast kv heads to q heads if needed

k_expanded = k.unsqueeze(2).expand(-1, -1, self.num_q_heads // self.num_kv_heads, -1, -1).reshape(b, -1, t, self.head_dim)

# v_expanded = v.unsqueeze(2).expand(-1, -1, self.num_q_heads // self.num_kv_heads, -1, -1).reshape(b, -1, t, self.head_dim)

A = torch.einsum("b h s d, b h t d-> b h s t", w, k_expanded) / math.sqrt(d // self.num_q_heads)

attn_mask = torch.tril(torch.ones(t, t),-1).unsqueeze(0).unsqueeze(1).to(x.device)

A = A.masked_fill(attn_mask == 0, 0)

if self.kernel_1 == ’linear’:

A = A.float()

elif self.kernel_1 == ’round’:

A = (RoundSTE.apply(A)).float()

elif self.kernel_1 == ’exp’:

A = torch.exp(A).float()

elif self.kernel_1 == ’softmax’:

A = torch.softmax(A, dim=-1).float()

elif self.kernel_1 == ’relu’:

A = torch.relu(A).float()

A = A*self.w_weight

group_size = self.num_q_heads // self.num_kv_heads

A_reshaped = A.view(b, self.num_kv_heads, group_size, t, t)

A = A_reshaped.mean(dim=2) # shape: (B, num_kv_heads, s, s)

u = torch.linalg.solve_triangular(self.beta * A, self.alpha * v, upper=False, unitriangular=True).to(k_expanded)

u = u.unsqueeze(2).expand(-1, -1, self.num_q_heads // self.num_kv_heads, -1, -1).reshape(b, -1, t, self.head_dim)

scores = torch.einsum(’bhtd,bhsd->bhts’, q, k_expanded) / math.sqrt(d // self.num_q_heads)

attn_mask = torch.tril(torch.ones(t, t)).unsqueeze(0).unsqueeze(1).to(x.device)

if self.kernel_2 == ’linear’:

attn = scores.masked_fill(attn_mask == 0, 0)

out = torch.einsum(’bhts,bhsd->bthd’, attn, u)

elif self.kernel_2 == ’round’:

attn = (RoundSTE.apply(scores)).masked_fill(attn_mask == 0, 0)

out = torch.einsum(’bhts,bhsd->bthd’, attn, u)

elif self.kernel_2 == ’softmax’:

scores = scores.masked_fill(attn_mask == 0, float(’-inf’))

attn = torch.softmax(scores, dim=-1).to(x.dtype)

out = torch.einsum(’bhts,bhsd->bthd’, attn, u)

elif self.kernel_2 ==’relu’:

attn = torch.relu(scores).masked_fill(attn_mask == 0, 0)

out = torch.einsum(’bhts,bhsd->bthd’, attn, u)

out = out.reshape(b, t, d)

return self.out(out)

class TransformerBlock(nn.Module):

##  11 Analytical Solution of Associative Memory

Without loss of generality, consider the memory optimization objective in terms of the L2 norm:

| ℒt​(𝑺t−1)=12​‖𝑺t−1​𝒌t−𝒗t‖2.\displaystyle\mathcal{L}_{t}(\bm{S}_{t-1})=\frac{1}{2}\|\bm{S}_{t-1}\bm{k}_{t}-\bm{v}_{t}\|^{2}. |  | (112)

| 𝑺∗=arg⁡min𝑺⁡𝔼𝒙​[12​‖𝑺​𝑾k​𝒙−𝑾v​𝒙‖2],\displaystyle\bm{S}^{*}=\arg\min_{\bm{S}}\mathbb{E}_{\bm{x}}\left[\frac{1}{2}\|\bm{S}\bm{W}_{k}\bm{x}-\bm{W}_{v}\bm{x}\|^{2}\right], |  | (113)
